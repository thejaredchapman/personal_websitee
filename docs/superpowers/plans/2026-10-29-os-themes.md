# OS Themes + Commit-Aware Splash Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Replace character themes and accent colors with four OS themes (XP, Win95, MySpace, Ubuntu), each with light and dark, and make the boot splash show the latest git commit in the active OS style.

**Architecture:** `ThemeContext` owns `os` and `theme` (mode) and mirrors them to `<html data-os data-theme>`. One CSS file per OS under `src/themes/` defines semantic tokens (including `--accent-*`) per mode plus chrome rules for `.os-*` classes. Vite injects the latest commit as `__GIT_COMMIT__`; `utils/buildInfo.js` exposes it; the boot screen is split into a timing shell plus four skins.

**Tech Stack:** React 19, Vite 7, Tailwind 4, Vitest + Testing Library.

## Global Constraints
- localStorage keys: `os-theme` (new), `theme-preference` (existing, unchanged semantics).
- OS ids: `xp | win95 | myspace | ubuntu`; default `ubuntu`. Mode values: `light | dark`; the context field stays named `theme`.
- Window positions/layout, mobile shell layout unchanged.
- No test for visuals beyond token/selector presence; verify visually in browser.
